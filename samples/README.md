# Samples

Fixtures for the tests. The `.eml` files are made-up announcements in the
shape of real ones — student-org emails, a career-office mailing, a firm
reception, a flyer newsletter — with invented events and placeholder links.
`vision/` holds three saved OCR readings of flyer images, one of them a public
event poster, its QR link replaced with a placeholder. Nothing here is anyone's
private email.

The screenshot at the top of the main README is built from these emails, with
their dates moved forward so the events are still to come:
`python3 tools/screenshot.py`.
